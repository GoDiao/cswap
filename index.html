What it does

Simple workflow, clean isolation.

01

Session isolation

Each run creates its own settings file. Different tabs can use different providers without affecting each other or your global config.

02

Quick add

Configure a new provider right from the selection UI. Name, URL, key, models — saved to ~/.cswap.json.

03

Pass-through

All flags go straight to Claude Code. --continue, --model, --dangerously-skip-permissions — anything.

04

Dual sources

Reads from CC Switch database and its own config file. Merged view, no lock-in to either system.

06

Cross platform

macOS, Linux, Windows. No native dependencies — just Node.js. Works wherever Claude Code runs.

05

Zero pollution

Never modifies your global ~/.claude/settings.json. Your hooks, plugins, and permissions are preserved.

How it works

1

Pick a provider

Run cswap and pick from the list, or use --provider to choose directly.

2

Settings generated

A settings file is generated with your provider's config. Your hooks and plugins carry over from global settings.

3

Claude launches

Claude Code launches with the generated settings. cswap exits and gets out of the way.

Install cswap

$npm install -g @godiao/cswap copied

Requires Node.js ≥ 18 and Claude Code
